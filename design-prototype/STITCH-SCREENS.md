# 工程管家 · Stitch 完整屏幕清单与提示词（Full Screen Pack）

> 目标：把整个软件每一屏都在 Stitch 里生成，形成像素级视觉真源，供落地实现照做。
> 用法：在**同一个 Stitch 项目**里，先发【第 0 段 全局设计系统】建立规矩，之后逐屏（或多屏连贯流）粘贴生成，风格会自动继承。
> 标注：🆕=新页型必做；⭐=招牌屏，值得多迭代打磨。
> 配套：IP 形象见 `MIORA-IP-BRIEF.md`；设计真源见 `DESIGN.md`。

> ## ⚠️ 屏 ↔ 导航页 映射（避免认错屏，务必先看）
> - **首页** = S7/S8/S9（AI 管家，不是数据看板）
> - **项目管理** = **S11（卡片/表格列表）** —— 你侧边栏点进去就是这个卡片网格。
> - **S10「投资组合概览/驾驶舱」= 无独立导航入口的可选概览屏**。真实侧边栏没有这一项，除非你决定它放哪，否则**建议跳过不生成**（上次就是把 S10 硬套到「项目管理」才对不上）。
> - 其余 S 屏基本一屏对一个导航模块，按标题对应即可。

## 第 0 段：全局设计系统（每个新项目先发这一段）

```
【全局设计系统 · 工程管家 Bedrock】先建立规矩，之后所有屏都继承：
- 近乎单色中性三主题：Paper 暖白纸（默认）/ Snow 清冷白 / Graphite 石墨黑（≈ Notion #191919）。全用 OKLCH，禁用纯 #000/#fff。
- 主色 = 墨色（亮色近黑 #2B2B2B / 暗色近白），靠明度对比强调；真正的彩色只用于语义状态（成功绿 / 警告琥珀 / 危险红 / 信息蓝），且低饱和、占比极小。
- 字体：UI 用 Inter + 思源黑体（Noto Sans SC）；金额 / KPI / 编号 / 日期用等宽 tabular 数字（JetBrains Mono），数字右对齐。
- 层次：分层表面 + 1px 发丝边 + 极柔和中性阴影；玻璃质感只用于浮层。
- 禁止：发光 / 霓虹 / 能量球、蓝紫渐变、渐变文字、彩色侧边竖条、深灰渐变 hero 横幅、千篇一律等大卡片墙、写实 3D。
- 气质：像 Linear / Notion / 苹果，克制、高级、办公专业，绝不 AI 味。

【业务真实性（务必遵守）】
- 货币一律 ¥ 人民币（绝不用 $）。
- **全中文铁律**：所有可见文字——分组标题、按钮、页脚、状态、示例数据——都必须中文，**禁止任何英文**（如 TODAY / EARLIER / MARK ALL AS READ / VIEW ALL / Navigate / Select / Status 等）。若飘出英文，就地追加一句"所有文字改成中文"重生成。
- 导航用真实模块名：首页 / 项目管理 / 合同管理 / 单位管理 / 人事管理 / 工人管理 / 结算办理 / 模板管理 / 发票管理 / 成本台账 / 仓库管理 / 图纸管理 / 语音知识库；系统区：用户管理 / 系统设置。
- 无自助注册、无找回密码（账号由管理员创建）。
- 桌面软件，无边框圆角窗口（系统的最小化/最大化/关闭三键由真实标题栏提供，Stitch 图里没有属正常，不用画）。
```

## 🎯 每屏通用视觉细则（每屏都套用，Stitch 违反就地纠正）

```
【组件级视觉细则 · 每一屏都适用】
- 边框：一律 1px 发丝边（黑 8% 透明，rgba(0,0,0,0.08)）。禁止死黑/粗黑边框；禁止给每个格子、每一行都描边（表格式全描边）。行与行之间用一条发丝分隔线或纯留白，不要"外框套内框"。
- 圆角：卡片 / 面板 / 下拉 / 弹窗一律 8–12px 圆角，禁止直角硬边。
- 阴影：浮层（下拉 / 命令面板 / 弹窗 / 通知）用极柔和 ambient 阴影（约 0 8px 40px、黑 4–6%、无偏移），禁止硬黑投影；普通卡片默认无阴影，只靠发丝边。
- 留白：条目内 padding 充足（约 12–16px）；图标与文字间距 8–12px；分组标题与条目之间有呼吸感。绝不拥挤、不贴边、不裁切。
- 背景：面板 / 卡片用纯白或 Paper 面色；浮层背后可极轻虚化。不要"灰底 + 硬黑框"那种未加工感。
- 文字：全中文；数字 / 金额 / 时间用等宽（tabular）。
- 图标：统一细线墨色（lucide 风格），尺寸统一 16–18px，与文字垂直居中对齐。
- 气质自检：像 Notion / Linear 的浮层那样"轻、柔、留白足"。若看起来像带黑边的 HTML 表格，就是错的，重做。
```

## 生成顺序建议

**结论：就按「组 A → 组 L」一组一组生成即可** —— 简单、不漏屏，而且组 A 天然打头就是 S0 外壳（壳定死，后面所有页都套它）。同一项目里风格自动继承，不必特意先做招牌屏。

- **S0 外壳最先**（它就在组 A 第一个，顺其自然）。
- **跳过 S10**（无导航入口）；「项目管理」只做 **S11 卡片网格**。
- 列表多的组（组 F 财务 / 组 G 单位·人事·工人）和表单类屏，**用「多屏连贯流」一次生成一组**，同类屏更一致、更省事。
- 招牌屏（⭐）多迭代一两轮打磨；普通屏一版满意即可，别反复抽卡浪费额度。
