# 工程管家 · Stitch 完整屏幕清单与提示词（Full Screen Pack）

> 目标：把整个软件每一屏都在 Stitch 里生成，形成像素级视觉真源，供落地实现照做。
> 用法：**全部屏幕放在同一个 Stitch 项目里**。仅在首次创建该 Stitch 项目时发送【第 0 段 全局设计系统】建立 Bedrock 规矩；之后每次生成新屏，直接引用已建立的设计系统，不要重复创建新的设计语言。逐屏（或多屏连贯流）粘贴生成，风格自动继承。
> 标注：🆕=新页型必做；⭐=招牌屏，值得多迭代打磨。
> 配套：IP 形象见 `MIORA-IP-BRIEF.md`；设计真源见 `DESIGN.md`。

> ## ⚠️ 屏 ↔ 导航页 映射（避免认错屏，务必先看）
> - **首页** = S7/S8/S9（AI 管家，不是数据看板）
> - **项目管理** = **S11A 卡片视图 + S11B 表格视图** —— 侧边栏点进去就是这个双视图列表。
> - **S10「投资组合概览/驾驶舱」= 无独立导航入口的可选概览屏**。真实侧边栏没有这一项，除非你决定它放哪，否则**建议跳过不生成**（上次就是把 S10 硬套到「项目管理」才对不上）。
> - 其余 S 屏基本一屏对一个导航模块，按标题对应即可。

## 第 0 段：全局设计系统（仅首次创建 Stitch 项目时发这一段）

```
【全局设计系统 · 工程管家 Bedrock】先建立规矩，之后所有屏都继承：
- 近乎单色中性三主题：Paper 暖白纸（默认）/ Snow 清冷白 / Graphite 石墨黑（≈ Notion #191919）。全用 OKLCH，禁用纯 #000/#fff（中性色一律向品牌色相染极低彩度）。
- 主色 = 墨色（亮色近黑 #2B2B2B / 暗色近白 #D4D4D4），靠明度对比强调；真正的彩色只用于语义状态（成功绿 / 警告琥珀 / 危险红），且低饱和、占比极小。
- 字体：UI 用 Inter + 思源黑体（Noto Sans SC）；金额 / KPI / 编号 / 日期用等宽 tabular 数字（JetBrains Mono），右对齐。
- 层次：分层表面（bg → panel → card 逐级提亮）+ 1px 发丝边 + 极柔和中性阴影；玻璃质感只用于浮层。
- 禁止：发光 / 霓虹 / 能量球、蓝紫渐变、渐变文字、彩色侧边竖条、深灰渐变 hero 横幅、千篇一律等大卡片墙、写实 3D、纯黑 / 纯白。
- 气质：参考 Linear 的信息秩序、Notion 的中性表面、苹果的精密细节，但不复制其品牌色 / 布局 / 组件造型；最终必须呈现"工程行业精密仪器"的独立视觉身份，绝不 AI 味。

【中文界面规则】
- 所有自然语言界面文案必须使用简体中文：标题、按钮、状态、分组名、占位文字、示例数据。
- 允许保留无法中文化的产品名 / 模型名 / 协议名 / 文件格式 / 快捷键，例如：AI、OCR、SQLite、GPU、Qwen3-ASR、API Key、Excel、ESC、⌘K、tokens。
- 技术标识必须配中文语境（如"SQLite 数据库：就绪""测试 API 连接"）；禁止 Navigate / Select / Ready / View All / TODAY / EARLIER / MARK ALL AS READ 等普通英文界面文案。飘出英文就地追一句"所有界面文案改成中文"重生成。

【业务真实性】
- 货币一律 ¥ 人民币（绝不用 $）。
- 导航用真实模块名：首页 / 项目管理 / 合同管理 / 单位管理 / 人事管理 / 工人管理 / 结算办理 / 模板管理 / 发票管理 / 成本台账 / 仓库管理 / 图纸管理 / 语音知识库；系统区（按权限可见）：用户管理 / 系统设置。
- 无自助注册、无找回密码（账号由管理员创建）。
- 桌面软件，无边框圆角窗口，**顶部标题栏由应用自身绘制**：标题栏右侧必须画出最小化、最大化 / 还原、关闭三个窗口控制按钮（关闭按钮仅在 hover 时显示危险红反馈）；不绘制浏览器标签栏、地址栏或网页导航控件。

【画布与桌面约束】
- 主应用基准画布：1440×900 桌面窗口，横向布局；关键内容在 1280×720 窗口下仍完整可用（表格允许在内容区内部滚动）。
- 侧边栏展开固定宽 256px；折叠态单独作为交互状态，普通屏不随机折叠。
- 标题栏高度在所有页面保持一致；底部状态栏固定约 24px。
- 主内容区按桌面软件设计，不要浏览器外壳、不要落地页式超长纵向网页。

【每屏输出约束】
- 每次只生成一个明确页面或一个明确交互状态；不要营销展示板 / 组件陈列板 / 多个页面拼贴。
- **例外**：S3、S37、S39 是通用组件与状态参考板，不属于业务页面，允许按各自提示同屏展示指定组件或状态；除此之外的业务页面严格遵守单屏单态。
- 每屏必须套用相同的 S0 应用外壳（登录、锁屏、启动页、图纸专注查看器除外）；侧边栏 / 标题栏 / 状态栏尺寸位置一致，不逐屏重新设计。
- 使用真实、合理但虚构的中文工程数据；不得使用 Lorem ipsum、美元、海外姓名或英文占位数据。
- 表格至少展示 6–8 行；金额 / 日期 / 编号右对齐或按列整齐对齐。
- 默认展示正常态，同时明确选中当前导航项；不要无故加入悬浮菜单、弹窗或手机布局。
- 不得自行增加 DESIGN.md 未定义的品牌色 / 渐变 / 发光 / 玻璃卡片 / 彩色插画。
- 输出的是可落地桌面产品界面，不是 Dribbble 概念图。
```

## 🎯 每屏通用视觉细则（每屏都套用，Stitch 违反就地纠正）

```
【组件级视觉细则 · 每一屏都适用】
- 边框：统一使用当前主题的语义 hairline 发丝边界色，1px。Paper / Snow 用极淡中性深色边界，Graphite 自动翻转为极淡中性亮色边界；不在提示里写死 rgba / hex / Tailwind 色阶。禁死黑 / 粗黑边框；禁止给每个格子、每一行都描边（表格式全描边）——行与行之间用一条发丝分隔线或纯留白，不要"外框套内框"。
- 圆角（按组件语义分级，同类必须一致）：按钮 / 导航项 / 状态标签 / chip = 9px；下拉 / 小型浮层 / 普通字段 = 10px；卡片 / 面板 / 弹窗 / 抽屉 = 16px；AI 对话输入等大型胶囊输入区 = 22px。禁直角硬边，禁把卡片和对话框都压成同一档小圆角。
- 阴影：浮层（下拉 / 命令面板 / 弹窗 / 通知）用极柔和 ambient 阴影（大扩散、低强度、中性色、几乎无偏移），禁硬黑投影；普通卡片默认无阴影，只靠发丝边与亮度分层。
- 表面：背景 / 面板 / 卡片使用同一主题内逐级变化的中性表面 bg → panel → card；Paper 保持轻微暖白纸感，不用刺眼纯白，也不得让所有层级塌成同一个白。
- 留白：条目内 padding 充足（约 12–16px）；图标与文字间距 8–12px；分组标题与条目之间有呼吸感。绝不拥挤、不贴边、不裁切。
- 文字：全中文；数字 / 金额 / 时间用等宽（tabular）。
- 图标：统一细线墨色（lucide 风格），尺寸统一 16–18px，与文字垂直居中对齐。
- 气质自检：像 Notion / Linear 的浮层那样"轻、柔、留白足"。若看起来像带黑边的 HTML 表格，就是错的，重做。
```

## 组 A · 全局外壳与浮层

**S0 应用外壳 ⭐**（导航壳，之后所有内容页都套这个）
```
桌面应用外壳：无边框圆角窗口。顶部一条应用自绘的细标题栏（左：品牌"工程管家"+ 极简三角 / 圆规几何 mark；中偏右：全局搜索框、通知铃、设置齿轮、用户头像；**最右侧画出最小化、最大化 / 还原、关闭三个窗口控制按钮**，关闭按钮仅 hover 时显示危险红）。左侧固定竖向侧边栏 256px（中文导航：首页 / 项目管理 / 合同管理 / 单位管理 / 人事管理 / 工人管理 / 结算办理 / 模板管理 / 发票管理 / 成本台账 / 仓库管理 / 图纸管理 / 语音知识库）；侧边栏底部固定系统操作区：管理员可见"用户管理"、有设置权限者可见"系统设置"，其下再显示当前用户名 + 角色、锁定 / 退出登录（用户管理 / 系统设置不混入所有用户都可见的普通业务导航）。选中项用整块淡色高亮 + 图标变墨色，无竖条。底部一条 24px 状态栏（当前页名、记录数、SQLite 就绪点、脱敏开关、主题切换）。出 Paper 亮色 + 一版 Graphite 暗色（主题锚点屏）。
```

**S1 全局命令面板（⌘K）⭐**
```
居中浮层命令面板（16px 圆角、1px 发丝边、极柔和 ambient 阴影，背景轻虚化；不要死黑边）。顶部大搜索输入框，占位"搜索页面、执行操作，或直接问 AI…"，右侧一个"ESC"小键帽。下分三组，分组标题用中文小标签"导航""AI 操作""快捷"：导航（跳各模块）、AI 操作（扫描超支风险 / 逾期回款催收 / 生成周报，带墨色图标）、快捷（切换主题 / 系统设置）。选中项整行淡色高亮 + 圆角，右侧显示快捷键。底部一条发丝分隔的提示栏，**全中文**："↑↓ 切换 · ↵ 选择"，右侧"状态：就绪"（禁止 Navigate / Select / Ready 等英文）。Paper 亮色。
```

**S2 通知面板**
```
从顶部铃铛下方展开的通知浮层：当前主题面板色（非纯白）、16px 圆角、1px 发丝边、极柔和 ambient 阴影、宽约 360px、不被裁切。顶部标题"通知中心"。按分组展示——分组标题"今天""更早"用小号墨灰标签。每条通知：最左细线墨色图标，中间标题（墨色）+ 摘要（灰，最多两行），右上角时间（等宽灰字，用"10:42""昨天""周一"这类中文 / 短格式）；未读在最左侧加一个小墨点。条目内 padding 充足（约 12–16px），条目之间只用一条发丝分隔线，禁止给每条描边成框。底部一行两个幽灵文字按钮"全部已读""查看全部"（无边框）。全中文、克制、无彩色底、无死黑边框。Paper 亮色。
```

**S3 全局态：Toast / 确认删除弹窗 / 加载骨架**
```
三个通用组件同屏展示：1) 右上角 Toast（成功 / 警告 / 错误三种）——状态只通过小型语义状态图标 + 简短中文状态文字表达，容器本身保持中性表面 + 发丝边，**不使用彩色左侧竖条，不整块铺语义色**；2) 居中确认弹窗"确认删除？此操作不可撤销"（取消 = 幽灵按钮，删除 = 危险红按钮）；3) 一个列表的加载骨架屏（灰条占位，非转圈）。Paper 亮色。
```

## 组 C · AI 管家（首页）

**S7 AI 主页·空态 ⭐**
```
AI 助手工作台首页（Paper）。正上方 AI 管家占位形象：**正圆球身 + 深色弧形脸屏 + 两只暖白表情眼，无手臂、无嘴、无天线**；珍珠白缎面球 + 深色脸屏，扁平中性占位。眼睛可有低亮度的屏幕自发光感，但不产生外溢光晕；球身、背景和轮廓均不发光；不霓虹、不写实 3D，之后可无缝替换为正式 IP 素材。下方居中问候"下午好，陈工"，再下方大圆角（22px）对话输入框（附件 / 麦克风 / 发送），下面一排快捷 chip：超支风险扫描 / 逾期回款 / 生成周报 / 语音转写。大量留白，禁统计卡片墙。
```

## 生成顺序建议

**结论：就按「组 A → 组 L」一组一组生成即可** —— 简单、不漏屏，而且组 A 天然打头就是 S0 外壳（壳定死，后面所有页都套它）。同一项目里风格自动继承，不必特意先做招牌屏。

- **首轮先试产 6 个代表屏验证不漂移**：S0（外壳）/ S7（AI）/ S11A（卡片）/ S16（表格）/ S30C（复杂工作流）/ S33（设置）。确认 Stitch 没有风格漂移（无死黑边、无飘英文、圆角分级正确、无纯白塌层）后，再批量生成其余屏幕。
- **S0 外壳最先**（它就在组 A 第一个，顺其自然）。
- **跳过 S10**（无导航入口）；「项目管理」做 **S11A 卡片视图 + S11B 表格视图**。
- 列表多的组（组 F 财务 / 组 G 单位·人事·工人）和表单类屏，**用「多屏连贯流」一次生成一组**，同类屏更一致、更省事。
- 招牌屏（⭐）多迭代一两轮打磨；普通屏一版满意即可，别反复抽卡浪费额度。

> 每组拿到满意版就**导出 zip 发我**；我按 `DESIGN.md` + shadcn 逐屏落地，并纠正 Stitch 的英文黑话 / 货币 / 字段。**不用等全部出完，你出一组、我落一组。**
