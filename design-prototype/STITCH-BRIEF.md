# Stitch 生成简报（Bedrock 设计语言）

> 用途：把本简报喂给 Google Stitch（stitch.withgoogle.com），生成符合「基石 / Bedrock」气质的原型。
> 关键优势：我们的 [DESIGN.md](../DESIGN.md) 用的就是 **Stitch 原生的 DESIGN.md 格式**，所以 Stitch 能直接读懂并遵守它。

---

## 第 0 步：先给 Stitch 立规矩（强烈建议）

在 Stitch 里新建项目后，**先用下面这段「全局指令」开场**（已更新为中性 纸/白/墨 方向），再开始生成。它会让 Stitch 遵守 Bedrock 的 token、字体、层次和铁律，而不是套用它自己的默认 SaaS 风或 AI 味。

> 注意：项目根目录的 `DESIGN.md` 颜色章节还是旧的电光蓝版本（待我同步为中性方向），**暂时别把 DESIGN.md 直接粘进 Stitch**，先用下面这段。

```
设计系统代号 Bedrock，北极星「精密仪器」，用户是坐办公室的项目经理/会计（不是工地）。硬性要求：
- 近乎单色的中性配色，全用 OKLCH，禁用纯 #000/#fff；单一语义 token（surface/panel/card/hairline/content/accent/state-*）。
- 三主题都是中性色：Paper（暖白纸，默认旗舰）/ Snow（清冷纯白）/ Graphite（中性石墨黑，纯灰无色偏）。先出 Paper。
- 主色 accent = 墨色（亮色主题近黑 / 暗色主题近白），只用于主操作/当前选中/焦点/状态；颜色只用于语义（成功绿/警告琥珀/危险红，且低饱和）。
- 金额/KPI 用等宽 tabular 数字（JetBrains Mono）；UI 用 Inter + Noto Sans SC。
- 层次靠分层表面 + 1px 发丝边 + 极柔和中性阴影；玻璃质感只用于浮层。
禁止：任何"发光/霓虹/能量球/电光蓝"式 AI 味；泛蓝或深蓝紫 SaaS 模板；深灰渐变 hero-metric 横幅；千篇一律等大卡片墙；满屏玻璃拟态；彩色侧边竖条；渐变文字；无意义装饰动画。目标是"高级克制的办公专业感"，像 Linear / Notion，不是复古后台，也不是科幻 AI。
```

## 第 1 步：逐屏 prompt（一次一屏，或让它做多屏连贯流）

### ① AI 管家主页（首页，招牌屏）
```
一个 AI 助手工作台首页（Paper 暖白纸主题，近乎单色）。正上方留一个圆形吉祥物占位（扁平、无发光、无霓虹，暂用一个带两只眼睛的中性圆形，之后替换为角色 IP），下方居中问候语「下午好，陈工」，再下方一个大圆角对话输入框（右侧发送按钮），输入框下方一排快捷提问 chip（超支风险扫描/逾期回款/生成周报/语音转写）。整体极简、居中、大量留白。禁止发光能量球、禁止统计卡片墙。
```

### ② 项目驾驶舱（数据高光屏）
```
一个工程项目管理驾驶舱页面。顶部标题「投资组合概览」+ 导出/新建按钮；下面一排 3 张 AI 洞察卡（带 AI 图标，主动风险提醒）；再一排 4 个 KPI，第一个 KPI 明显更大更强调（在建项目），其余三个较小（合同总额/待回款/组合健康度），数字用等宽字体带迷你趋势线；再下面左右两栏：左「成本 vs 回款趋势」面积图，右「发票状态」环形图 + 图例；最底一张「近期合同」数据表格，含状态药丸（履约中/待付款/逾期）。Paper 暖白纸主题（默认亮色，近乎单色、去荧光）。避免等大卡片墙，用大小制造层级。
```

### ③ 全局命令面板（⌘K，签名交互）
```
一个居中浮层命令面板（玻璃质感允许），顶部一个大搜索输入框（占位「搜索、执行操作，或直接问 AI…」），下面分三组条目：导航（打开 AI 管家/项目驾驶舱/发票管理）、AI 操作（扫描超支风险/逾期回款催收/生成周报，带 accent 图标）、快捷（切换主题）。条目右侧显示快捷键。Paper 暖白纸主题（默认亮色，近乎单色、去荧光），浮层背景虚化。
```

### ④ 发票管理（典型 CRUD 列表页）
```
一个发票管理列表页。顶部标题 + 筛选栏（类型/状态/项目/日期）+ 新建按钮；下方一个密集数据表格：列含发票号、对方单位、金额（等宽右对齐）、开票日期、状态药丸；行 hover 有 accent 淡色高亮。信息密度高但清爽，Paper 暖白纸主题（默认亮色，近乎单色、去荧光）。表格是主角，不要 hero 横幅。
```

### ⑤ 登录页 / 启动页（入场高光）
```
一个桌面软件登录页，无边框圆角窗口，Paper 暖白纸主题（默认亮色，近乎单色、去荧光）。中央品牌标记（三角几何 mark，accent 渐变）+ 软件名「工程管家」，下面用户名/密码输入框 + 主按钮「登录」，背景有极淡的生成式粒子/网格光效。高级、克制、有科技感，不要花哨。
```

### ⑥ 空状态 / 加载态（教学式）
```
为上述列表页设计空状态（暂无数据时）：居中一个精致线性插画 + 一句引导文案 + 一个「新建」主按钮；以及加载态：用骨架屏（skeleton）而非居中转圈。Paper 暖白纸主题（默认亮色，近乎单色、去荧光）。
```

## 第 2 步：导出（三选一，回流给我）

1. **DESIGN.md**（首选）：导出后发我，我把它与现有 `DESIGN.md` 合并/校准（同格式，几乎零摩擦）。
2. **React + Tailwind 代码**：导出后发我，我按仓库规范（语义 token / check-rules / 组件 API）改造落地，绝不直接照搬。
3. **截图 / 图片**：发我做视觉对照与实现校验。
4. （进阶）**Stitch MCP 直连**：配好后我可直接从 Stitch 项目拉取设计，免手动导出（见配置说明）。

## 备注：Stitch 的定位
Stitch 最适合**快速出招牌屏和创意探索**（AI 主页、驾驶舱、登录、空状态），不建议用它逐一生成 20 个密集 CRUD 页——那些交给 shadcn 组件 + 我按 Bedrock 落地更快更一致。
