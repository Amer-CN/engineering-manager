# AI 管家 IP 形象简报（给 miora.design）· EVE 风格 · 正圆

> 用途：在 miora 做出「工程管家」AI 助手吉祥物成品。把下面【可直接粘贴的提示词】发给 miora，拿回素材交给我集成。
> 决策：参考《机器人总动员》EVE 的头 —— **正圆球身 + 深色弧形脸屏(visor) + 两只表情眼**。身体必须【正圆】，**不要竖椭圆 / 蛋形**。缎面高级质感（不是廉价镜面亮塑料，也不是死哑光）。miora 出成品，前端集成。
> 参考件：仓库 `design-prototype/mascot-eve.html` 是造型 + 交互参考（正圆球身 + 深脸屏 + 眼睛跟随鼠标 + 眨眼 + 四态）。
> 基准：Bedrock「精密仪器」气质，见 `DESIGN.md`。

---

## 一、角色定位
- 用户是坐办公室的项目经理 / 会计：专业、可信、亲和。
- **深色脸屏天生"设备 / 仪器感"**，正好契合 Bedrock「精密仪器」，比"白胖子长脸"高级。
- 靠眼睛表达情绪；安静克制，不吵闹、不低龄。

## 二、造型（硬要求）
- **身体：正圆球体（perfect sphere）—— 不要竖椭圆、不要蛋形。** 缎面 / 珍珠白微光表面（柔和高光，不是镜面亮塑料，也不是完全死哑光）。
- **脸屏：一块深色弧形面板**，占球体上中部，把眼睛衬得精神。
- **眼睛：两只干净的表情眼**，能上下左右看（跟随鼠标）；默认暖白微光。
- **无**天线、**无**手臂、**无**嘴（情绪全靠眼睛）。
- 中性配色：珍珠白 / 浅灰球 + 深色脸屏；32–48px 也清晰；透明背景；亮底（暖白纸）/ 暗底（石墨）都好看。

## 三、眼睛配色（三选一，默认暖白）
- **暖白微光**（推荐，高级不 AI 味）
- **EVE 淡蓝微光**（最像伊娃，略带 AI 味）
- **纯墨不发光**（最保守，最融进纸面）

## 四、状态与交互（灵魂）
- **眼睛跟随鼠标**（第一优先）。
- 待机（眨眼 + 轻呼吸）/ 思考（眼上移 + …）/ 聆听（眼微放大）/ 完成（弯眼笑）。

## 五、交付（按优先级）
- **3D Hero**：`.glb / .gltf` 模型优先（可嵌 viewer 做头 / 眼跟随）；否则多表情高清透明 PNG + idle 循环。
- **2D 交互版**：`Rive(.riv)`（含状态机 + "look" 输入）；出不了我用 `mascot-eve.html` 那套 SVG 兜底（几乎不耗额度）。

## 六、额度 / 设置
- miora 仅 1000、H3D 较贵：先出 1 个满意造型，再出表情。
- Agent 用 **Max**（指令跟随最强），3D 用 **H3D 3.1**。
- 止损：造型改 2 次仍不对，回退 SVG（已就绪）。

## 七、可直接粘贴的提示词

### 提示词 1 · 造型（先发这个，图片模型即可）
```
帮我为一款工程项目管理软件（工程管家）设计一个 AI 助手吉祥物，参考《机器人总动员》里 EVE 的头的感觉，但做成我的独立形象。
造型：一个【正圆的球体】身体（务必正圆，不要竖椭圆、不要蛋形），表面是干净的缎面 / 珍珠白微光（柔和高光，不要廉价镜面亮塑料，也不要完全死哑光）；球体上中部有一块【深色弧形脸屏】，脸屏上是两只干净、友善、会表达情绪的大眼睛（暖白色微微发光）。不要天线、不要手臂、不要嘴。
气质：专业、可信、克制、高级，像苹果 / EVE 那种精密设备感的桌面小伙伴；中性配色，能同时放在浅色和深色界面上。
先给我 2–3 个造型草案（正面），聚焦：正圆球身 + 深色脸屏 + 两眼。
```

### 提示词 2 · 3D + 表情（造型满意后，用 H3D，Agent 调 Max）
```
把选定的这个造型做成 3D：正圆球体、缎面珍珠白、深色弧形脸屏、两只暖白微光的眼睛；柔和影棚光，球体可有柔和高光但不要镜面刺眼反光，不要发光霓虹、不要蓝紫渐变。
做 4 种表情（靠眼睛）：待机 / 思考 / 聆听 / 完成，外加一段 idle 呼吸循环。
导出：优先 .glb / .gltf 模型（或含"看向鼠标"输入的 Rive）；否则每个表情一张透明背景高清 PNG + idle 循环。
```
> 想更像伊娃：把眼睛换成"淡蓝微光"；想最保守：改"纯墨色不发光"。
