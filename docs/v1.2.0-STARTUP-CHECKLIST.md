## 阶段 A：PiiProtector 基础设施（4-6h）

### A.1 新建 `EngineeringManager.Api/Security/PiiProtector.cs`

```csharp
public class PiiProtector
{
    // master key 用 Windows DPAPI 加密后存 %APPDATA%\工程管家\pp.key
    // 运行时解密 master key，再用 AES-GCM 加密 PII
    public string Encrypt(string plain) { ... }   // base64 ciphertext
    public string Decrypt(string cipher) { ... }  // plaintext
}
```

**关键设计**：
- DPAPI: `ProtectedData.Protect(masterKey, null, DataProtectionScope.CurrentUser)`
- AES-GCM: `System.Security.Cryptography.AesGcm` (.NET 8 内置)
- Master key 32 字节（首次启动随机生成）
- 异常时 throw + log，不 swallow

## 阶段 B：30 端点改造（4-6h）

### B.1 INSERT 改造

```csharp
// 之前
var newMember = new { Name = dto.Name, IdCard = dto.IdCard, ... };
await db.ExecuteAsync("INSERT INTO members (..., id_card, ...) VALUES (..., @IdCard, ...)", newMember);

// 之后
var pii = HttpContext.RequestServices.GetRequiredService<PiiProtector>();
var newMember = new {
    Name = dto.Name,
    IdCard = dto.IdCard,           // 保留原字段做编辑时回填（可选）
    IdCardEnc = pii.Encrypt(dto.IdCard),  // 加密存储
    ...
};
await db.ExecuteAsync("INSERT INTO members (..., id_card_enc, ...) VALUES (..., @IdCardEnc, ...)", newMember);
```

### B.2 SELECT 改造

```csharp
// 之前
var members = await db.QueryAsync<Member>("SELECT * FROM members");

// 之后
var pii = HttpContext.RequestServices.GetRequiredService<PiiProtector>();
var members = (await db.QueryAsync<Member>("SELECT * FROM members")).Select(m => new {
    ...m,
    idCard = pii.Decrypt(m.IdCardEnc ?? ""),  // 列出时解密
});
```
