**[11:09]** 跨端设计时，不要直接把web端控件缩小后搬到APP里。第一，导航外端用侧边栏，信息量大，切换速度快，适合鼠标精准操作。APP专用底部导航，拇指可达区域内，单手操作更方便。第二，分页web专用页码精准跳转，可以直接跳转到任意一页。APP端用连续滚动上滑，自然加载更多内容，符合移动端浏览习惯。第三批量选择，web端用复选框批量操作，高效直观，适合高频管理场景。APP端用长按进入选择模式，适配非高频操作，避免误触。

**[11:45]** 第四，刷新web端，点击刷新按钮重新加载数据明确触发。APP端用下拉手势刷新，手感更自然，有弹性反馈。第五，地址选择web专用三级级联选择器，三列并排快速填写APP专用定位加滚轮触控更符合移动端操作习惯。

**[12:04]** 第六，图片浏览web端用灯箱加左右箭头点击翻页APP专用全屏沉浸式浏览，左右滑动手势翻页。第七，悬浮提示Y专用鼠标power就近解释，精量便捷APP专用点击popover明确触发，避免误操作。跨端设计不是简单缩放web页面，而是要针对不同设备的操作逻辑，重新选择适配的控件和交互方式。
