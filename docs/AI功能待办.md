## 技术说明

### 已有基础设施
- 百度 OCR API（身份证 + 发票识别共用）
- SQLite 数据库（支持复杂查询）
- 前端组件库（表格、图表、表单）

### 不需要 AI API 的功能
- 重复发票检测（规则引擎）
- 数据异常检测（规则引擎）
- 智能填表（数据关联）
- 批量操作（前端逻辑）
- 报表生成（数据汇总 + 模板）

### 未来可考虑（需要 AI API）
- 自然语言查询（等 AI 更成熟）
- 合同条款分析（需要 LLM）
- 智能风险预警（需要 LLM）
