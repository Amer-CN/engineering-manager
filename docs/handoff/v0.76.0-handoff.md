### 累计待办 #5: PII 列级 key rotation (`ef79f0c`)

**最大改动, 9 文件 +720 行, 0 破坏性**:

- migration 023 `023_AddPiiKeyRotation.sql`: `pii_keys` 表
  ```sql
  CREATE TABLE pii_keys (
      key_id INTEGER PRIMARY KEY AUTOINCREMENT,
      encrypted_key BLOB NOT NULL,  -- DPAPI 加密的 32 字节 AES-256 master key
      is_active INTEGER NOT NULL DEFAULT 0,
      created_at TEXT NOT NULL,
      created_by TEXT,
      retired_at TEXT
  );
  ```
- `PiiProtector.cs` 重构为多 key 加密:
  - 内存 `Dictionary<int, byte[]> _keysById` 持有所有活跃 + 历史 key
  - 密文格式升级: `base64(version[1] || nonce[12] || tag[16] || ciphertext)`
  - 旧 v1.2.0 密文兼容: 无 version 字节 → fallback 到 key_id=1 (legacy)
  - `Initialize(IDbConnection db)`: 启动时加载所有 key, pii_keys 空时从 `%APPDATA%\工程管家\pp.key` 迁移
  - `Rotate(IDbConnection db, adminUid)`: 生成新 key, 旧 active 标 retired_at, 写 pii_keys
  - `ListKeys(IDbConnection db)`: admin 看 rotation 历史
- 端点: `EngineeringManager.Api/Endpoints/PiiKeyEndpoints.cs`
  - `GET /api/admin/pii/keys`: 列所有 key (key_id, is_active, created_at, retired_at, created_by)
  - `POST /api/admin/pii/rotate`: admin-only, 写 audit_logs (action=update, resource=pii_keys, level=warning)
- UI: `src/components/features/settings/SettingsPiiKeySection.tsx`
  - 卡片显示: 当前 active key_id / 历史 key 总数 / 最近轮换时间
  - "立即轮换" 按钮: confirm 对话框 → 调 rotatePiiKey
  - 解释文案: 旧 key 保留, 新 key 加密新数据, 无停机
- Tests: `EngineeringManager.Tests/Security/PiiProtectorTests.cs` (11 个)
  - Initialize / Encrypt-Decrypt roundtrip / Empty / LongString / Rotate / OldCiphertext 仍可解 / NewCiphertext 用新 key / Legacy 格式 fallback / Initialize 幂等 / 未初始化抛异常
- 32/32 → 40/40 (29 旧 + 11 新)

**升级路径 (v0.75.3 → v0.76.0)**:
1. 重启 C# 服务, 自动跑 migration 023
2. 首次启动: PiiProtector 从 %APPDATA%\工程管家\pp.key 导入到 pii_keys (key_id=1)
3. 现有 PII 密文继续可读 (旧格式自动 fallback)
4. (可选) admin 在 Settings → PII 加密密钥 → 立即轮换, 生成 key_id=2
