## 7. 关键经验教训 (本会话)

1. **mimo 适合**: 阅读代码 → 产出 patch → 应用 Edit 工具改文件 (绕过 shell, 走 AI 工具)
2. **mimo 不适合**: 大量 git 命令 / 大量文件批量操作 / 长时间执行 (5 min timeout)
3. **mimo wrapper bug**: `.git` 会被重命名为 `.git-mimo`, mimo 内部所有 git 命令失败 (workaround: 任务里让 mimo 用 `mv .git-mimo .git` 或 Codex 自己跑)
4. **路线图时效性**: handoff 文档列的路线图可能已过时, 接新窗口时务必先验证 (本会话 #2 #4 都过时)
