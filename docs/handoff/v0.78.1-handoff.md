## 本次改动

PiiReencryptWorker 性能优化: 全量 SELECT → chunked 分批 + 逐行 UPDATE → batch 事务提交。

| 改动 | 说明 |
|------|------|
| chunked SELECT | 每批 500 行 (WHERE id > lastId ORDER BY id LIMIT 500), 内存友好 |
| batch UPDATE | 每 50 行开一次事务, 减少 SQLite WAL 写入压力 |
| 进度粒度 | 每 50 行更新进度表, 前端 3s 轮询可见变化 |
