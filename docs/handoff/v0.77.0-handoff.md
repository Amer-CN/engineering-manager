## 8. 关键经验教训 (本会话 + 之前)

1. **mimo 适合**: 单文件 React patch (含新建子文件) — n=2 一次过率 100%
2. **mimo 不适合**: 任何 git 命令 / 5+ 分钟长任务
3. **mimo wrapper bug**: .git 被改名, mimo 内部所有 git 命令失败 (workaround: 任务里不要求 git, 收尾 Codex 做)
4. **路线图时效性**: handoff 列的路线图可能已过时, 接新窗口时务必先验证
5. **PowerShell 7 Get-Content 行为变化**: `Measure-Object -Line` 返回 1, 需用 `-split "`n"` 算真实行数
6. **UTF-8 BOM 陷阱**: PowerShell `[System.IO.File]::WriteAllText` 默认带 BOM, 改 PowerShell 7+ 或用 `[System.Text.UTF8Encoding]::new($false)` 避免
7. **Git add 不会取消已 staged**: 第二次 `git add` 后 commit, 已 staged 的会一起被提交 (v0.76.0 commit 1 教训)
