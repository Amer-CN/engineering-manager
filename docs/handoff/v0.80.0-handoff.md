### mimo 调用模板 (v0.80.0 修正后)

```powershell
$prompt = Get-Content "prompt.txt" -Raw

# 关键: 用 mimo.exe 直接 (不通过 mimo.ps1), stdin 传 prompt, cwd 已是项目根
$proc = Start-Process -FilePath "C:\Users\Admin\AppData\Roaming\npm\node_modules\@mimo-ai\mimocode-windows-x64\bin\mimo.exe" `
  -ArgumentList "run", "-m", "mimo/mimo-auto" `
  -RedirectStandardInput "prompt.txt" `
  -RedirectStandardOutput "output.log.stdout" `
  -RedirectStandardError "output.log.stderr" `
  -WorkingDirectory "E:\测试" `
  -WindowStyle Hidden `
  -PassThru
```

**重要: mimo prompt 里 cd 命令不要带中文路径**. 写 `npx tsc --noEmit` 直接调 (mimo cwd 已在项目根). 否则 PS 解析错误 + mimo hang.

⚠️ 不要用 `mimo run --prompt-file` — 不支持.
⚠️ 不要用 `mimo.ps1 run` wrapper — v0.80.0 测过会出现 PS 路径解析问题.
⚠️ mimo 进程可能 hang (bug #1132), 跑超过 5 min 就 Stop-Process.

### PowerShell 替换陷阱

- **CRLF vs LF**: `.Replace` 必须用 CRLF (`[char]13 + [char]10`) 才能匹配多数源码文件; AGENTS.md, CHANGELOG.md 之类文档可能是 LF-only
- **`*` 在双引号字符串**: PowerShell 把 `**` 当乘法, here-string 里也要用单引号 `@'...'@`
- **`${var}` 在双引号字符串**: PowerShell 7 解析有问题, 用 `.Replace()` 替代 `${}` interpolation
- **BOM**: `[System.IO.File]::WriteAllText` 默认 UTF-8 with BOM, 用 `[System.Text.UTF8Encoding]::new($false)` 避免
- **mimo + PS 中文路径**: mimo prompt 里不要 `cd E:\测试 && ...`, 直接 `npx ...`

### git 约束

- mimo 跑时 .git 被改名 .git-mimo, 跑完会恢复; 如果 mimo crash, 手动 `Rename-Item .git-mimo .git`
- `git add -A` 然后 reset 单个文件用 `git reset HEAD <file>`
- package-lock.json 在 .gitignore 里 (用 `git add -f` 强制)
- 没有 origin remote, `git push` 会失败

## 6. 经验教训 (v0.80.0 新增)

### mimo 适配模式 (n=7)

- **必过**: 单文件 React patch, 含新建子文件 (100% 一次过, n=6)
- **必败**: 任何 git 命令 (wrapper 把 .git 改名触发 EEXIST)
- **高风险**: 5+ min 任务, shell 复杂命令
- **新发现**: PS 中文路径 + mimo verification = 5min hang. 解决: mimo prompt 里不写 `cd 中文路径 &&`, 直接 `npx` 调用

### PowerShell 中文路径陷阱

- mimo 内部用 `cd E:\测试 && ...` 验证 tsc, 触发 PS 解析错误 + mimo retry loop hang
- 修复: mimo prompt verification step 用纯英文路径或省略 cd (mimo cwd 已在项目根)

### 项目工程经验

- **拆超大组件前先看 hook 依赖**: StaffAttendance 拆分要确认 sub-page return (timeline + detail) 是否在主组件, 不要全拆
- **测试用 getByRole / getByText 优于 querySelector**: Portal 渲染 + getByTitle (Tooltip) 是 testing-library 最佳实践
- **Tooltip 包按钮**: v0.78.0 Tooltip 加 native title fallback 后, 所有 icon-only 按钮都要包 Tooltip, 让 getByTitle 测试工作 + 无障碍
- **CI 红绿灯要包括 type check**: tsc 错误累积起来比 lint 错误更隐蔽, 加进红绿灯能强制 type-safe
