### mimo 调用模板 (v2.5 已稳定, v0.82.0 直接用)

```powershell
$mimoExe = "C:\Users\Admin\AppData\Roaming\npm\node_modules\@mimo-ai\mimocode-windows-x64\bin\mimo.exe"
$promptFile = "E:\测试\.mimo-runs\v0.83.0\task-xxx-prompt-xxx.txt"
$logFile = $promptFile -replace "prompt", "log"

"" | Out-File -FilePath $logFile -Encoding utf8

$proc = Start-Process -FilePath $mimoExe `
  -ArgumentList "run", "-m", "mimo/mimo-auto" `
  -WorkingDirectory "E:\测试" `
  -RedirectStandardInput $promptFile `
  -RedirectStandardOutput "$logFile.stdout" `
  -RedirectStandardError "$logFile.stderr" `
  -WindowStyle Hidden `
  -PassThru
```

**重要**: mimo prompt 里 cd 命令不要带中文路径. 写 `npx tsc --noEmit` 直接调.
⚠️ mimo 进程可能 hang (bug #1132), 跑超过 5 min 就 Stop-Process.
⚠️ mimo 跑时 .git 被改名 .git-mimo, 跑完会恢复; 如果 mimo crash, 手动 `Rename-Item .git-mimo .git`

### PowerShell 替换陷阱

- **CRLF vs LF**: `.Replace` 必须用 CRLF (`[char]13 + [char]10`) 才能匹配多数源码文件; AGENTS.md, CHANGELOG.md 之类文档可能是 LF-only
- **`*` 在双引号字符串**: PowerShell 把 `**` 当乘法, here-string 里也要用单引号 `@'...'@`
- **`${var}` 在双引号字符串**: PowerShell 7 解析有问题, 用 `.Replace()` 替代 `${}` interpolation
- **BOM**: `[System.IO.File]::WriteAllText` 默认 UTF-8 with BOM, 用 `[System.Text.UTF8Encoding]::new($false)` 避免
- **mimo + PS 中文路径**: mimo prompt 里不要 `cd E:\测试 && ...`, 直接 `npx ...`
- **mimo.exe 直接调用**: 不要包 ps1 wrapper tee, 会有 Add-Content 中文路径编码 bug
