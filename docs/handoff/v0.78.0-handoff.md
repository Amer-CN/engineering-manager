## 7. 关键经验教训 (本会话 + 之前)

1. **mimo 适合**: 单文件 React patch (含新建子文件) — n=2 一次过率 100%
2. **mimo 不适合**: 任何 git 命令 / 5+ 分钟长任务 / ts 错误诊断 / runtime bug 调试
3. **mimo wrapper bug**: .git 被改名, mimo 内部所有 git 命令失败
4. **路线图时效性**: handoff 路线图可能已过时, 验证后可能跳过
5. **PowerShell 7 Get-Content 行为变化**: `Measure-Object -Line` 返回 1, 用 `-split "`n"` 算真实行数
6. **UTF-8 BOM 陷阱**: PowerShell `[System.IO.File]::WriteAllText` 默认带 BOM, 用 `[System.Text.UTF8Encoding]::new($false)` 避免
7. **Git add 不会取消已 staged**: 第二次 `git add` 后 commit, 已 staged 的会一起被提交
8. **Git diff 审查不充分**: v0.77.0 commit 7f9da39 mimo 漏了 `import type` 让 types 不可用, 我只审 diff 没跑 tsc. **下次必跑 tsc --noEmit 验证**
9. **vitest 测不到的 bug**: v0.75.0-v0.77.0 List 页面 runtime 崩溃, vitest 没真正 import 那些 List, build 也不做 type check. **下次接新窗口先跑 tsc --noEmit**
