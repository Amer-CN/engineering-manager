## 2. 关键改动详情

### #1: OCR 8 处假成功修复

**核心问题 (P1-1 安全残留, v0.76.0 没碰)**:

`OcrEndpoints.cs` 8 个 OCR 端点的 catch 块返回 `Results.Ok(new { success = false, error = ... })`:
- HTTP 200 但 success=false → 前端可能误判为成功
- 错误信息直接泄露 `ex.Message` (P1-3 信息泄露)

**修复方案**:

1. 新增 `CatchOcrError(string endpointName, Exception ex)` private static helper
   - 服务端: `Console.Error.WriteLine` log 完整 ex.Message
   - 客户端: 友好提示, 不泄露内部路径/堆栈
   - HTTP 状态码: 500 (真错误, 不是假成功)
   - 返回: `Results.Json(new { success = false, error = userMsg }, statusCode: 500)`

2. 8 个 OCR 端点 catch 块替换:
   - `/api/ocr/id-card` → `CatchOcrError("ocr-id-card", ex)`
   - `/api/ocr/invoice` → `CatchOcrError("ocr-invoice", ex)`
   - `/api/ocr/bank-card` → `CatchOcrError("ocr-bank-card", ex)`
   - `/api/ocr/business-license` → `CatchOcrError("ocr-business-license", ex)`
   - `/api/ocr/bank-receipt` → `CatchOcrError("ocr-bank-receipt", ex)`
   - `/api/ocr/permit` → `CatchOcrError("ocr-permit", ex)`
   - `/api/ocr/bank-statement` → `CatchOcrError("ocr-bank-statement", ex)`
   - `/api/ocr/general-receipt` → `CatchOcrError("ocr-general-receipt", ex)`

## 4. 修复前后对比

**修复前 (P1-1 安全问题)**:
\`\`\`csharp
catch (Exception ex)
{
    return Results.Ok(new {
        success = false,
        error = ex.Message.Contains("超时")
            ? "百度OCR请求超时，请检查网络连接"
            : $"百度OCR请求失败: {ex.Message}"
    });
}
\`\`\`

**问题**:
- HTTP 200, 但 success=false — 前端可能不检查 success 字段, 误以为是成功
- `ex.Message` 直接返回给前端 — 泄露内部路径/堆栈/数据库错误细节

**修复后 (真 500)**:
\`\`\`csharp
catch (Exception ex)
{
    return CatchOcrError("ocr-id-card", ex);
}
\`\`\`

`CatchOcrError` 实现:
\`\`\`csharp
private static IResult CatchOcrError(string endpointName, Exception ex)
{
    Console.Error.WriteLine($"[OcrEndpoints/{endpointName}] OCR失败: {ex.Message}");
    var userMsg = ex.Message.Contains("超时")
        ? "百度OCR请求超时，请检查网络连接"
        : "百度OCR识别失败，请稍后重试或检查图片质量";
    return Results.Json(new { success = false, error = userMsg }, statusCode: 500);
}
\`\`\`

**优势**:
- HTTP 500, 前端正确识别为错误
- 服务端 log 完整 ex.Message (调试用)
- 客户端收到脱敏友好提示, 不泄露内部细节
