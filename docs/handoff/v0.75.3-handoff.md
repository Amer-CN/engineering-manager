### 重要: 版本策略 (新)
详见 `AGENTS.md` §🔢 版本管理. 简言之:
- `feat(...)` → minor bump
- `fix(...)` → patch bump
- `refactor(...)` → **不 bump**
- `docs(...)` / `chore(...)` → **不 bump**

refactor-only sprint 不打 tag, 不 bump version. 只有真正改了行为的 commit 才打 tag.
