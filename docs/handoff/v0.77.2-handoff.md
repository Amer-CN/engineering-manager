### 修复模式

**修复前**:
```csharp
catch (Exception ex) {
    return Common.Fail($"参数解析失败: {ex.Message}");  // 泄露内部堆栈/路径
}
```

**修复后**:
```csharp
catch (Exception ex) {
    return Common.Fail($"参数解析失败: {Common.Sanitize(ex.Message)}");  // 脱敏
}
```

`Common.Sanitize()` (v0.76.0 P1-3 引入): 移除 Windows 绝对路径 (`C:\Users\...\file.cs` → `C:\...\file.cs`), 截断到 200 字符.
