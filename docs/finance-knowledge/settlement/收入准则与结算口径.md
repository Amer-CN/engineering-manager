# 收入准则与结算口径

> settlement/（结算模块）

### JS01 新收入准则核心定义
依据：《企业会计准则第14号——收入》（财会〔2017〕22号，自 2018-01-01 起施行，取代 2006 版收入准则）第 26、28、41 条｜状态：有效｜最后验证：2026-09-06
内容：合同履约成本——企业为履行合同发生的成本，不属于其他企业会计准则规范范围且同时满足三条件（该成本与一份当前或预期取得的合同直接相关；该成本增加了企业未来用于履行履约义务的资源；该成本预期能够收回），应当确认为一项资产。合同取得成本——企业为取得合同发生的增量成本预期能够收回的，应当确认为一项资产；摊销期不超过一年的可以在发生时计入当期损益；增量成本指不取得合同就不会发生的成本（如销售佣金）。合同资产——企业已向客户转让商品而有权收取对价的权利，且该权利取决于时间流逝之外的其他因素。合同负债——企业已收或应收客户对价而应向客户转让商品的义务。
代码触点：结算/成本台账的领域概念基线。

### JS02 施行衔接与准则适用分叉（工程行业关键）
依据：财会〔2017〕22号《关于修订印发〈企业会计准则第14号——收入〉的通知》（2017-07-05，mof.gov.cn 原文）通知第一条 + 《小企业会计准则》（财会〔2011〕17号）附录科目表｜状态：有效｜最后验证：2026-09-08
内容：
- 施行时间（通知第一条原文三段式）：在境内外同时上市的企业以及在境外上市并采用国际财务报告准则或企业会计准则编制财务报表的企业，自2018年1月1日起施行；其他境内上市企业，自2020年1月1日起施行；**执行企业会计准则的非上市企业，自2021年1月1日起施行**；允许提前执行。（勘误注记：本条目此前所引"施行日期调整文件（财会〔2018〕15号）"查无实据——原文即直接规定三段式日期，该引用已删除。）
- 原准则处理（官方措辞）：执行本准则的企业，**不再执行**财会〔2006〕3号中的《企业会计准则第14号——收入》与《企业会计准则第15号——建造合同》，以及财会〔2006〕18号中的旧收入应用指南。注意官方原文是"不再执行"而非"废止"。
- 准则分叉（小企业会计准则，财会〔2011〕17号附录科目表）：**不含**合同资产/合同负债/合同履约成本科目（全文字检索三词各 0 次，双独立来源一致）；成本类科目仅有 4001 生产成本、4101 制造费用、4301 研发支出、**4401 工程施工**、4403 机械作业。即小企业（建筑业）以 4401 工程施工核算实际发生的工程成本（按"合同成本"和"间接费用"明细核算，期末借方余额反映未完工的建造合同成本和合同毛利），**没有"工程结算"科目**（"工程结算"是 2006 企业会计准则应用指南体系的科目，不属于小企业准则）。
- 结论：结算模块的会计口径必须先确认目标企业执行的准则体系——执行企业会计准则的（2021-01-01 起全面适用新收入准则）：合同履约成本/合同结算/合同资产/合同负债体系；执行小企业会计准则的：工程施工（4401）等科目体系且无合同结算科目。两套口径不得混用。工程管家作为单机软件无法替用户选准则，功能设计应保持业务口径（进度款/质保金/结算单）与会计科目口径解耦。
- 证据注记：小企业准则附录科目表经维基文库与 MaoDocs 两个独立来源逐字核验一致（gov.cn 国务院公报刊载版正文不含附录科目表，财政部原件 Word 附件直链未定位）。
代码触点：结算模块若引入科目概念需明确目标准则或保持解耦。

### JS03 实务科目用法（合同结算与质保金）
依据：《〈企业会计准则第14号——收入〉应用指南（2018）》（维基文库与《企业会计准则应用指南汇编》第十五章双源逐字核验）+ 应用指南汇编【例15-90】质保金案例｜状态：有效（出版级——应用指南为财政部会计司编写组官方出版物文本，非文号文件）｜最后验证：2026-09-08
内容：
- 合同结算科目（应用指南原文）：同一合同下的合同资产和合同负债应当以净额列示，企业可以设置"合同结算"科目核算某一时段履约义务下与客户结算对价形成的合同资产或合同负债；其下设两个明细——"**合同结算——价款结算**"（反映定期与客户进行结算的金额）、"**合同结算——收入结转**"（反映按履约进度结转的收入金额）。
- 期末余额列报（原文，注意按流动性划分）：期末余额在**借方**的，根据其流动性，在资产负债表中分别列示为"合同资产"或"其他非流动资产"项目；在**贷方**的，分别列示为"合同负债"或"其他非流动负债"项目。
- 合同资产与应收款项的区分（原文）：应收款项代表无条件收取合同对价的权利（仅随时间流逝即可收款）；合同资产不是无条件收款权——除时间流逝外还取决于其他条件（例如履行合同中的其他履约义务）。
- 质保金账务处理（应用指南汇编第十五章【例15-90】，甲建筑公司 580 万固定造价合同，30 万质保金，逐字要点）：质保期内质保金挂在"合同结算"科目借方（"2x21年6月30日，'合同结算'科目的余额为借方30万元……是工程质保金……应当在年末资产负债表中作为合同资产列示"）；质保期结束且未发生重大质量问题：**借：应收账款 贷：合同结算**；实际收到价款：借：银行存款 贷：应收账款。
代码触点：质保金字段/状态机设计（质保期内=合同资产性质挂账、期满转应收）；报表口径注意流动性划分（一年内/以上）。
