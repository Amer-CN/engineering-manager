# 收入准则与结算口径

> settlement/（结算模块）

### JS01 新收入准则核心定义
依据：《企业会计准则第14号——收入》（财会〔2017〕22号，自 2018-01-01 起施行，取代 2006 版收入准则）第 26、28、41 条｜状态：有效｜最后验证：2026-09-06
内容：合同履约成本——企业为履行合同发生的成本，不属于其他企业会计准则规范范围且同时满足三条件（该成本与一份当前或预期取得的合同直接相关；该成本增加了企业未来用于履行履约义务的资源；该成本预期能够收回），应当确认为一项资产。合同取得成本——企业为取得合同发生的增量成本预期能够收回的，应当确认为一项资产；摊销期不超过一年的可以在发生时计入当期损益；增量成本指不取得合同就不会发生的成本（如销售佣金）。合同资产——企业已向客户转让商品而有权收取对价的权利，且该权利取决于时间流逝之外的其他因素。合同负债——企业已收或应收客户对价而应向客户转让商品的义务。
代码触点：结算/成本台账的领域概念基线。

### JS02 施行衔接与准则适用分叉（工程行业关键）
依据：财会〔2017〕22号 + 施行日期调整通知（疑为财会〔2018〕15号）｜状态：待复核｜最后验证：未验证
内容：执行《企业会计准则》的企业——上市公司自 2018-01-01 施行，其他非上市企业自 2021-01-01 全面施行；原《企业会计准则第15号——建造合同》随之废止，"工程结算、工程施工——合同毛利"科目体系被"合同履约成本、合同结算、合同资产/合同负债"体系替代。**分叉（重要）**：执行《小企业会计准则》（财会〔2011〕17号）的中小企业——工程管家的典型客户群——其附录科目体系未同步引入合同资产/负债概念，建造承包商科目（工程施工/工程结算等）在该准则体系下仍在使用（具体科目清单待复核小企业会计准则附录）。
结论：结算模块的会计口径必须先确认"目标企业执行哪套准则"，两套口径不得混用。工程管家作为单机软件无法替用户选准则，功能设计应保持业务口径（进度款/质保金/结算单）与会计科目口径解耦。
代码触点：结算模块若引入科目概念需明确目标准则或保持解耦。

### JS03 实务科目用法（质保金）
依据：《CAS14 应用指南》科目部分 + 事务所实务文章综述｜状态：非官方待复核（L2）｜最后验证：2026-09-06
内容：合同结算科目按应用指南设"价款结算"（对应应收对价）与"收入结转"（对应收入确认）两个明细方向，期末借方余额呈合同资产性质、贷方余额呈合同负债性质；工程质保金在质保期内先记合同资产，质保期满转应收账款。
代码触点：质保金字段与状态机设计参考；取证升级前不得作为实现依据。
