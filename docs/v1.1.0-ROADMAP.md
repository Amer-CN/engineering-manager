### S1.3 — 改所有 SELECT 端点（4-6h）

```csharp
app.MapGet("/api/income-contracts", async (long projectId, HttpContext ctx, IDbConnection db) =>
{
    var uid = CurrentUser.GetUserId(ctx);
    var isAdmin = CurrentUser.IsAdmin(ctx);
    return await db.QueryAsync(@"
        SELECT * FROM income_contracts
        WHERE project_id = @ProjectId
          AND (created_by = @Uid
               OR @IsAdmin = 1
               OR EXISTS(SELECT 1 FROM project_members
                         WHERE project_id = @ProjectId AND user_id = @Uid))",
        new { ProjectId = projectId, Uid = uid, IsAdmin = isAdmin ? 1 : 0 });
});
```

### S1.4 — 改所有 DELETE/UPDATE 端点（2-4h）

```csharp
app.MapDelete("/api/income-contracts/{id}", async (long id, HttpContext ctx, IDbConnection db) =>
{
    var uid = CurrentUser.GetUserId(ctx);
    var isAdmin = CurrentUser.IsAdmin(ctx);
    var affected = await db.ExecuteAsync(@"
        DELETE FROM income_contracts
        WHERE id = @Id
          AND (created_by = @Uid OR @IsAdmin = 1)",
        new { Id = id, Uid = uid, IsAdmin = isAdmin ? 1 : 0 });
    return affected > 0 ? Results.Ok(new { success = true })
                         : Results.Forbid();
});
```

## 风险与缓解

| 风险 | 缓解 |
|------|------|
| migration 改错破坏现有数据 | 跑前 `cp engineering.db engineering.db.before-v1.1.0` |
| 80 query 改造漏改导致数据泄露 | sprint B 末尾写自动化扫描：`grep "WHERE.*project_id" Endpoints/*.cs` |
| 老数据 `created_by IS NULL` 处理 | 决定：admin 可见，所有人不可见；写文档告知用户 |
| 性能：每 query 加 3 个 OR 条件 | 索引：19 个 `idx_*_created_by` 已在 migration 010 创建 |
| 用户误删 P0-3-A 后端 mask 导致 UI 双重 mask | 前端 mask 改条件渲染 `masked ? mask : value`；后端 mask 后前端默认 `masked=true` 跳过 |
