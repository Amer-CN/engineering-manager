# 报告打印契约（REPORT PRINT CONTRACT）

> 版本：v1.0 · 2026-09-13 · 依据 v0.96.0 代码实测确立
> 地位：**规范性文档**。报告（文本版 + 四个图形版模板）的纸面版式一律以本文件为准。
> 与 `DESIGN.md` 的关系：DESIGN.md 管**屏幕**设计 token；本文件管**纸面**。两者数值不通用
> （屏幕 px 观感 ≠ 打印 pt 观感），改动时分别对照。

---

## 0. 为什么需要这份文件（教训来源）

2026-09-08～09-13 连续多轮报告排版返工，根因是**参照物用错**：把 lieflat-charts 的
12 张模板当作版式真源，而它们是**网页单页设计稿，从未为 A4 打印验证过**。由此产生的
字号偏小、分页半空、书脊溢出、行距挤压、SVG 缩放、长名裁切等问题，全部属于下面定义的
**B 层**，不在该设计库的职责内。

本文件把这一晚实测确立的数字与规则固化下来：**今后改报告版式，先对照本契约，再查设计库。**

## 1. 三层职责划分（本契约只管 B）

| 层 | 范围 | 真源 | 说明 |
|----|------|------|------|
| A 图表本身 | 图型选择、配色、数据编码、条长比例 | lieflat-charts skill（`~/.zcode/skills/lieflat-charts/`） | 只借它的**图表视觉语言** |
| **B 纸面排版** | 字号/行高/页边距/分页/书脊/溢出/有效可读性 | **本文件** | 打印工程，设计库不管 |
| C 应用内 UI | 弹窗、预览组件、交互 | 前端设计 skill（impeccable / ui-ux-pro-max） | 不用图表 skill 做 UI |

**数据展示是否实用**（该不该放这个指标）属产品决策，不由上述任何 skill 决定。

## 2. 字号契约

纸面 pt 为验收口径，CSS px 为实现口径；换算固定 **1px = 0.75pt**（96dpi，浏览器打印 100%）。

| 层级 | 纸面 pt | CSS px | 现值落点（已实现） |
|------|---------|--------|-------------------|
| 正文 | **10.5pt（中文五号）** | 14px | `.section p` / `.section li` / `.tb td` = 14px |
| 元信息/来源/说明 | 9pt | 12px | `.kpi .r/.l`、页眉、卡注 = 12px |
| 小节标题 | 12pt | 16px | `.claim` = 16px |
| 章节标题 | 14pt | 19px | `.secthead .t` = 19px |
| 图表轴/网格标签 | ≥7.5pt | ≥10px | 一律 10px 起 |
| 图表数据标签/注脚 | ≥8.25pt | ≥11px | 一律 11px 起 |
| 装饰英文 eyebrow | 7.5pt | 10px | `.srcline` = 10px |
| 海报大字/大数字 | ≥20px | 不动 | 书脊 56px、kpi 38px 等为设计意图 |

**硬下限：打印产物中任何文字不得低于 10px（=7.5pt）。** 中文笔画密度高，同字号比拉丁更难读，
所以正文基准取五号，不再往下压。

## 3. 物理页约束

```
@page { size: A4; margin: 10mm 0 }      /* r01 / r05 / r12：左右满版出血 */
@page { size: A4; margin: 14mm 12mm }   /* 文本版 + r04 图形版：常规页边距 */
```

不可协商的物理事实（用户已知悉，勿试图"修掉"）：
- `@page` 边距区域**铺不了底色** → 上下纸边只能是白色；
- 左右满版出血时，若上下不留纸边，中间页文字会贴顶 → 现行契约 = **上下 10mm 白边 + 左右满版**；
- 打印对话框勾选"页眉和页脚"会渲染 `about:blank`，代码不可控，用户取消勾选即可。

## 4. 分页规则

| 元素 | 规则 |
|------|------|
| `.section`（整节） | **允许跨页**（不得设 `break-inside:avoid`——否则大节整节推下页，前一页大片空白） |
| `.secthead` / `.claim` | `break-after:avoid`（防节标题孤悬页底） |
| `.tablewrap` / `.chartblk` / `.stats` / `.tophead` / `.foot` | `break-inside:avoid`（表格、图卡、大数字块保持原子） |

流式长文只能在中性位置断页，做不到海报式逐页构图——这是流式排版的固有限制。

## 5. 书脊规则

竖排大标题**必须按标题长度自适应**，否则长标题（含期间括号，22 字以上）超出页高被裁尾，
并与底部标签叠印；固定书脊逐页重复，会**每一页都烂**。

```
spineFs = max(24, min(56, floor(900 / 标题字符数)))   /* 900 = 页高预算，扣底部标签区 */
```

短标题（≤16 字）保持 56px 原设计不变。

## 6. SVG 与 viewBox 陷阱（本契约最重要的一条）

**SVG 内 `font-size` 是 viewBox 坐标单位，不是纸面像素。** 实际印出大小：

```
有效 px = 声明 px × (渲染宽度 ÷ viewBox 宽度)
```

历史上因此栽过两次：
- r12 条形图画布 460、卡片实宽约 284（scale 0.617）→ 声明 10px 印成 4.6pt；
- r04 条形图画布 620、容器约 587（scale 0.947）→ 声明 10px 印成 7.1pt。

**规则：**
1. 字号验收**必须看纸面有效字号**（从 PDF 提取），只查 HTML 声明值等于没查；
2. 若画布宽 > 渲染宽（文字被缩小），按 scale 反算补偿声明值，或把 viewBox 改为容器宽；
3. SVG 文字**超出 viewBox 会被硬裁**（无自动换行）→ 单行标签一律走宽度感知截断
   `fitSvgText(name, maxUnits, cjk, ascii)`，超宽补 `…`，禁止无声丢字。

## 7. 条形图几何（打印侧）

| 项 | 规则 | 现值 |
|----|------|------|
| 标签区 | 必须容得下真实类目名（约 17 汉字 / 34 ASCII） | `X0=198`、标签右对齐 `x=190`、`BARMAX=330` |
| 轨道线 | **不画**发丝轨道（官方 tick rows 的基线是给刻度队列站立的；实心条画它会穿过数值） | 已移除 |
| 数值位置 | 紧跟条尾（`X0+w+10`），不右对齐固定列；一律加粗墨色 | — |
| 行距 | 必须容得下"标签 + 条形 + 数值"三层；画布高度按行数计算，不写死 | r12：行距 56、`H=58+(n-1)×56` |
| 徽章/固定宽容器 | 宽度按内容动态计算，禁止写死（长数值曾被裁成 `99999.00`） | r01 证据带 `numW=max(54, 文本宽+16)` |
| 条长 | 严格正比，不断轴不从零截断；预留数值列的封顶系数须对**同一容器同一系数**（否则最长条被 flex 压缩、比例失真） | 预览 `scaleX×75%` |

## 8. 结构与列表支持（文本版）

- 打印链与预览链**能力必须对齐**：有序列表 `1. `、无序 `- `、表格、`> 引用行`、
  `#`~`####` 标题层级，两侧都要支持（历史上打印链不支持 ol，编号被印成普通段落）。
- **编号保真**：`<ol>` 必须带 `start="原编号"`，沿用 AI 写的序号；列表被子项打断后重开
  也要保持续排，禁止浏览器从 1 重编。
- `> 期间：…` 引用行：提取为报告期间并进书脊底部，正文不再裸露 `>` 字面量。
- 结论句（claim）**只认列表/表格之前的先行散文行**；纯列表节、表格在前的节不得提升
  （否则节尾页脚行会被搬到节首加粗）。

## 9. 预览 / 打印同值契约

同一元素在预览（React 组件）与打印（静态 HTML/SVG 生成器）中**字号值必须相同**。
- HTML 文字：按声明值比对；
- SVG viewBox 内文字：坐标系不同，**按纸面有效字号比对**，不按声明值。

## 10. 验证方法（改动后必做）

1. **结构体检**：四模板 × 三场景（完整/空/注入）生成打印 HTML，断言零 `<script>`、
   无 `${`/undefined/NaN 泄漏、div 配平、@page 正确、注入被转义；
2. **打印分页核验**（截图模式看不出分页）：HTML 复制到**纯英文路径**（CJK 路径
   print-to-pdf 会静默失败）→ Edge 无头 `--print-to-pdf` → **PyMuPDF 提取每段文字的实际
   pt 字号**，断言无 <7.5pt → 逐页渲染 PNG **肉眼验收**（提取不感知视觉裁切/叠印，必须看图）；
3. **压力数据**：长类目名、6 行以上、超大金额、走势图——固定构图问题只在极端数据下暴露；
4. **预览核验**：无头截图前注意两个环境假象：framer-motion 组件 SSR 停在 `opacity:0`、
   审计页 CSS 必须用**绝对路径**（相对路径会解析到 `.work/dist/` 导致整页无样式，
   把布局问题误判成组件缺陷）。
