# 百度 OCR 配置指南

## 概述

工程管家接入百度 AI 开放平台的 OCR 服务，支持 9 种智能识别功能，覆盖身份证、发票、银行卡、营业执照、银行回单等常见业务单据。

## 快速配置

1. 打开工程管家 → **系统设置** → **AI 智能识别**
2. 选择 **AI 智能识别** 模式
3. 输入 API Key 和 Secret Key
4. 点击 **保存配置** → **检测连接**

## 申请百度 OCR API

### 步骤 1：注册百度智能云账号

访问 [百度智能云控制台](https://console.bce.baidu.com/)，注册并登录。

### 步骤 2：开通文字识别服务

1. 进入控制台，搜索「文字识别」
2. 进入「文字识别服务」页面
3. 点击「开通服务」
4. 领取免费资源包（个人认证免费）

### 步骤 3：创建应用

1. 进入「应用列表」→「创建应用」
2. 填写应用名称（如：工程管家）
3. 勾选需要的识别功能：
   - 身份证识别
   - 增值税发票识别
   - 银行卡识别
   - 营业执照识别
   - 银行回单识别
   - 通用文字识别（用于开户许可证、通用票据）
4. 创建成功后获取 **API Key** 和 **Secret Key**

### 步骤 4：填入软件

将 API Key 和 Secret Key 填入工程管家的 AI 智能识别设置中。

## 支持的识别功能

| 功能 | 集成位置 | 自动填入的字段 |
|------|----------|---------------|
| 身份证识别 | 工人录入 | 姓名、身份证号、性别、民族、出生日期、住址 |
| 增值税发票识别 | 发票管理 | 发票号、日期、金额、税率、商品名称、销售方/购买方 |
| 银行卡识别 | 工人工资卡 | 银行卡号、银行名称 |
| 营业执照识别 | 合作单位 | 公司名称、统一社会信用代码、地址、经营范围 |
| 银行回单识别 | 收付款记录 | 交易日期、金额、收付款方 |
| 开户许可证识别 | 合作单位 | 统一社会信用代码、公司名称 |

## 离线模式

不配置百度 API 时，软件使用离线模式（Tesseract.js），仅支持身份证号识别（从图片中提取数字），其他字段需要手动输入。

## 常见问题

**Q: 识别失败怎么办？**
检查网络连接，确保可以访问 `aip.baidubce.com`。如果网络不通，身份证识别会自动回退到离线模式。

**Q: API Key 泄露了怎么办？**
立即在百度智能云控制台删除该应用，重新创建新的 API。

**Q: 免费额度用完了怎么办？**
购买资源包，或等待下月零点重置。
