### 任务 3：P2.3 — check-rules.cjs 添加 btn 检测规则

**问题**：`scripts/check-rules.cjs` 已有 hex 颜色、gray-、text-[Npx] 检测，缺少 btn CSS 类检测。

**变更**：在铁律七部分（第266行后）添加规则 4：

```javascript
// 规则 4：禁止 btn CSS 类（已从 index.css 删除，阻断新增）
const btnClassFiles = walkTsxFiles(SRC, f =>
  !f.includes('__tests__') && !f.includes('node_modules') && !f.includes('prototype'))
let btnViolations = 0
for (const file of btnClassFiles) {
  const content = fs.readFileSync(file, 'utf-8')
  const lines = content.split('\n')
  lines.forEach((line, i) => {
    if (/className[=:].*\bbtn-(primary|secondary|danger|ghost|warning|success|sm|lg)\b/.test(line)) {
      const rel = path.relative(ROOT, file)
      console.log(`  HARD FAIL  ${rel}:${i + 1}: ${line.trim()}`)
      btnViolations++
    }
  })
}
if (btnViolations > 0) {
  console.log(`  共 ${btnViolations} 处 btn CSS 类违规，请用 <Button> 组件替代`)
  violations += btnViolations
}
```

**验证**：`node scripts/check-rules.cjs` → btn-* 0 违规

### 任务 5：P3.1 — JWT 认证

**问题**：无认证机制，所有 API 端点公开可访问。

#### 5.1 后端变更

**NuGet 包**：
```bash
dotnet add package Microsoft.AspNetCore.Authentication.JwtBearer --version 8.0.*
```

**Program.cs**：
- 添加 `using System.Text;`, `using Microsoft.AspNetCore.Authentication.JwtBearer;`, `using Microsoft.IdentityModel.Tokens;`
- `ConfigureServices()` 添加 JWT 认证配置（SymmetricSecurityKey, TokenValidationParameters）
- `ConfigureApp()` 添加 `app.UseAuthentication(); app.UseAuthorization();`
- 全局授权策略：`options.DefaultPolicy = RequireAuthenticatedUser`

**AuthEndpoints.cs**：
- 添加 `GenerateJwtToken()` 方法（HMAC-SHA256, 7天过期）
- 登录端点返回 `token` 字段
- 登录端点添加 `[AllowAnonymous]`
- 用户/角色端点添加 `.RequireAuthorization()`

**HealthEndpoints.cs**：
- 健康检查端点添加 `[AllowAnonymous]`

**BackupEndpoints.cs**：
- 备份/恢复/诊断端点添加 `[AllowAnonymous]`

#### 5.2 前端变更

**api-client.ts**：
- 添加 `authToken` 变量 + `setAuthToken()` / `getAuthToken()` 函数
- `getHeaders()` 自动添加 `Authorization: Bearer xxx`
- 所有请求方法（get/post/put/del）添加 401 处理：`handleUnauthorized()` 清除 token + 触发 `auth:unauthorized` 事件

**tauri-bridge.ts**：
- `login` / `authLogin` 方法改为 async，登录成功后调用 `setAuthToken(result.data.token)`

**AuthContext.tsx**：
- 导入 `setAuthToken`
- `logout()` 中调用 `setAuthToken(null)` 清除 token

**验证**：`dotnet build` 零错误，`npx vite build` 构建成功
