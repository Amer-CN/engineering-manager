### 任务 3：P2.3 — check-rules.cjs 添加 btn 检测规则

**问题**：`scripts/check-rules.cjs` 已有 hex 颜色、gray-、text-[Npx] 检测，但**缺少 btn CSS 类检测规则**。

**需要添加**：

文件：`scripts/check-rules.cjs`

在铁律七部分（约第197行开始）添加：

```javascript
// 规则 4：禁止 btn CSS 类（已从 index.css 删除，阻断新增）
console.log('\n  ── btn CSS 类检测 ──')
const btnClassFiles = walkTsxFiles(SRC, f =>
  !f.includes('__tests__') && !f.includes('node_modules') && !f.includes('prototype'))
let btnViolations = 0
for (const file of btnClassFiles) {
  const content = fs.readFileSync(file, 'utf-8')
  const lines = content.split('\n')
  lines.forEach((line, i) => {
    // 检测 className="...btn-..." 或 className={`...btn-...`}
    if (/className[=:].*\bbtn-(primary|secondary|danger|ghost|warning|success|sm|lg)\b/.test(line)) {
      const rel = path.relative(ROOT, file)
      console.log(`  HARD FAIL  ${rel}:${i + 1}: ${line.trim()}`)
      btnViolations++
    }
  })
}
if (btnViolations > 0) {
  console.log(`  共 ${btnViolations} 处 btn CSS 类违规，请用 <Button> 组件替代`)
  violations += btnViolations
}
```
